# Projeto de Data Analytics com Power BI — DIO

## Sobre o projeto
Projeto desenvolvido para o desafio **Projeto de Data Analytics com Power BI**, da DIO. O repositório documenta a construção de um relatório analítico e criativo no Microsoft Power BI, com foco em transformar dados em informações úteis para tomada de decisão.

## Objetivos
- Aplicar conceitos de Data Analytics no Power BI.
- Criar um relatório visual, organizado e interativo.
- Utilizar indicadores e gráficos adequados ao contexto analisado.
- Trabalhar filtros, segmentações e navegação entre páginas.
- Organizar a entrega em um repositório de portfólio no GitHub.

## Estrutura proposta do relatório

### Página 1 — Visão Geral
Painel executivo com os principais indicadores, cartões de KPI e visão consolidada dos resultados.

### Página 2 — Análise de Desempenho
Visualizações para comparação de resultados por categoria, período, produto, segmento ou outra dimensão disponível na base.

### Página 3 — Análise Detalhada
Detalhamento dos dados com filtros e segmentações, permitindo investigar padrões, tendências e pontos relevantes.

## Boas práticas aplicadas
- Hierarquia visual e organização dos elementos.
- Uso de KPIs para destacar informações importantes.
- Segmentadores para tornar a análise interativa.
- Gráficos escolhidos de acordo com o tipo de informação.
- Organização do projeto para publicação no GitHub.
